# 化学实验室（ChemLab）

一款面向 **安卓低性能手表（Android 9 / Wear OS 2，API 28）** 的模拟化学实验游戏。
纯 Kotlin + Android Framework Canvas 矢量绘制，无 AndroidX、无图片资源、无多余依赖，体积小、功耗低。

## 一、已实现的功能

| 需求 | 实现方式 |
| --- | --- |
| 1. 简单示意图标 | `IconRenderer.kt` 用 Canvas 矢量绘制烧杯、试管、锥形瓶、集气瓶、蒸发皿及火焰、气泡、物质圆点 |
| 2. 常用器材 + 加热/混合/溶解 | 5 种器材（烧杯/试管/锥形瓶/集气瓶/蒸发皿）；酒精灯加热、搅拌溶解、通电电解、蒸发结晶、冷却、清洗 |
| 3. 常见所有物质 | 单质、气体、氧化物、酸、碱、盐等 **136 种**物质，含溶解性、外观颜色、溶液颜色属性 |
| 4. 物质间化学反应 | 覆盖 **四大基本反应（化合/分解/置换/复分解）+ 氧化还原**，内置 211 条反应，按计量比实时反应 |
| 5. 适配安卓9低性能 | minSdk 25，Canvas 纯绘制，600ms 低刷新率 tick，无后台常驻 |
| 6. 成就系统 | 18 项成就，本地 SharedPreferences 持久化 |
| 7. 实时显示实验状态 | 顶部温度/状态徽标 + 可滚动状态区，实时显示物质、温度、水量、反应记录与现象 |

## 二、操作方法

1. **开始实验** → 进入实验台。
2. **加物质** → 打开物质选择面板（分类：单质/氧化物/酸/碱/盐），点击即加入一勺/一份试剂。
3. **加水** → 加入 60 mL 溶剂水；**搅拌溶解** → 把可溶固体溶入水中、让反应物充分混合。
4. **加热 / 熄灭** → 酒精灯持续升温（最高 800℃）；多数氧化还原、分解需达到条件温度。
5. **点燃** → 一次性引燃，触发燃烧类反应（如 C + O₂、Mg + O₂、H₂ + O₂）。
6. **通电 / 断电** → 触发电解类反应（如电解水生成 H₂ 与 O₂）。
7. **冷却** → 立即降到 25℃；**蒸发结晶** → 蒸干水分析出晶体；**换器材** → 切换容器；**清洗** → 清空容器。

> 提示：固体需“搅拌溶解”或充分接触后才会参与溶液反应；气体反应会在容器内自动进行。

## 三、反应规则

- 反应引擎按反应物中“限制反应物的摩尔量”成比例进行反应，无需一次性凑满整化学计量比。
- 反应需满足三个条件才会发生：
  1. 各反应物均存在；
  2. 相态约束（复分解需有溶液环境、置换需金属固体接触溶液）；
  3. 外界条件（温度 / 点燃 / 通电 / 催化剂）。
- 一次 `tick`（约 0.6s）内引擎会循环结算全部可发生的反应，并把方程式与现象写入状态区。

## 四、成就一览

初次实验、小小加热员、溶解大师、气体制造者、沉淀观察员、中和反应、化合能手、分解达人、置换先锋、复分解专家、氧化还原王者、四大基本反应、燃烧吧、通电分解、催化剂的作用、初识物质（10 种）、物质图鉴（30 种）、实验室老手（累计 20 次）。

## 五、构建与运行

```bash
cd ChemLab
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

- 若本机未安装 Android SDK，请先配置 `ANDROID_HOME`（命令行）或 Android Studio 打开后同步。
- Gradle Wrapper 7.5 · Android Gradle Plugin 7.4.2 · Kotlin 1.8.22 · compileSdk 33 / targetSdk 33 / minSdk 25。

## 六、项目结构

```
app/src/main/java/com/chemlab/game/
  MainActivity.kt   入口 Activity（承载 GameView、串联成就持久化）
  Substance.kt      物质数据模型 + 136 种物质注册表
  Equipment.kt      器材数据
  Reaction.kt       四大基本反应 + 氧化还原反应数据库 + 反应引擎
  GameState.kt      容器/会话状态与操作（加物质、加热、搅拌、电解、蒸发…）
  GameView.kt       主界面渲染与触摸交互（标题/实验台/物质选择/成就/图鉴）
  IconRenderer.kt   Canvas 矢量示意图标
  Achievements.kt   成就系统（SharedPreferences 持久化）
```

## 七、适配说明

- 采用全屏沉浸式主题，界面按屏幕百分比布局，适配圆形/方形小表盘。
- 600ms 低刷新率、无颜色渐变与位图，显著降低电量与渲染开销。
- 全局手势：列表上下滑动查看、点击选择，返回键通过界面「‹」或底部返回热区。
